# Android loyihasi

Bu papka Android ilova uchun boshlang'ich skeleton bo'lib xizmat qiladi.

## Reja
- `com.wifi.locator` package tuzilmasi
- `MainActivity.kt` uchun asosiy UI
- `WiFiScanner.kt` yoki `WifiRepository.kt` uchun Wi‑Fi skanlash logikasi
- `LocationHelper.kt` uchun foydalanuvchi joylashuvi
- `GeolocationService.kt` uchun Mozilla API so'rovi
- `MapScreen.kt` yoki `MapFragment.kt` uchun xarita ko'rinishi

## Keyingi bosqich
- Android Studio proyektini yaratish
- Kotlin + AndroidX + MapLibre integration
- Location va Nearby Wi‑Fi ruxsatlari
- 1 km radius filter

## Ishga tushirish uchun
- Android Studio o'rnatildi
- JDK 17+
- Android SDK sozlangan bo'lishi kerak

Ushbu loyiha keyinchalik to'liq ishlab chiqiladi.
