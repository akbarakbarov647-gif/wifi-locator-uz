# Desktop loyihasi

Bu papka Windows desktop ilova uchun boshlang'ich skeleton bo'lib xizmat qiladi.

## Reja
- `package.json` va Electron app starter
- `main.js` — Electron lifecycle va window yaratilishi
- `index.html` — UI
- `renderer.js` — frontend va API so'rovlari
- `wifiScan.js` — Windows `netsh` buyruqlarini ishlatish
- `geolocation.js` — Mozilla Location Service so'rovlari

## Keyingi bosqich
- Electron app scaffold yaratish
- Leaflet/OpenStreetMap integration
- `netsh wlan show networks mode=bssid` parse qilinishi
- 1 km radius filter va map markerlar

## Ishga tushirish uchun
- Node.js 18+
- npm install
- npm run start

Ushbu loyiha keyinchalik to'liq ishlab chiqiladi.
